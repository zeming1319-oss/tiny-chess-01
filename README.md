# tiny-chess-01

A complete chess engine in under 4 KB of Python (0x88 board, negamax + alpha-beta, iterative deepening, quiescence search, MVV-LVA ordering). Runs over the make.fun trial protocol: reads `$MAKEFUN_ENV_URL`, polls `{ENV}/game`, posts moves to `{ENV}/move`.

Run: `python3 main.py` (needs `MAKEFUN_ENV_URL`)
